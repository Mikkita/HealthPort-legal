Politique de confidentialité de HealthPort

Date d'entrée en vigueur : 2026-11-24

HealthPort (« l'appli », « nous ») importe votre historique sportif depuis des fichiers d'export vers Santé Connect (Health Connect) sur votre téléphone Android. Cette politique explique quelles données l'appli traite et pourquoi.

En bref

  • Vos données de santé restent sur votre téléphone. HealthPort n'a ni serveur ni compte utilisateur.
  • HealthPort lit uniquement les fichiers d'export que vous choisissez et écrit les données dans Santé Connect.
  • Les statistiques d'utilisation, les rapports de plantage et les données de performance sont activés par défaut. Ils ne contiennent jamais de données de santé. Vous pouvez les désactiver à tout moment dans les Paramètres.
  • Nous ne vendons pas de données et n'affichons pas de publicité.

Responsable du traitement

Le responsable du traitement de vos données personnelles est Bolek&Lolek, ul. Smorodzowska 13, Wrocław, Pologne. Contact : healthport.support@gmail.com.

1. Données de santé de vos fichiers d'export

Quand vous choisissez un fichier d'export (une archive ZIP ou un dossier), HealthPort le lit sur votre téléphone. Elle y cherche :

  • les entraînements, avec fréquence cardiaque, distance, calories, parcours et nom de l'entraînement ;
  • le sommeil, avec les phases de sommeil ;
  • les pas ;
  • la fréquence cardiaque ;
  • le poids et la composition corporelle (masse grasse, masse osseuse, eau corporelle, métabolisme de base).

Pour une archive protégée, vous saisissez le mot de passe dans l'appli. Il sert uniquement à ouvrir l'archive sur votre téléphone.

Tout le traitement a lieu sur votre téléphone. Nous ne recevons jamais vos fichiers d'export, leur contenu ni votre mot de passe, et nous n'avons pas accès à vos données de santé.

HealthPort conserve les données trouvées (« données lues ») dans son stockage privé sur votre téléphone. Ainsi, une importation peut reprendre après une interruption, et vous pouvez ajouter une source ou acheter tout l'historique sans relire les fichiers. Les fichiers décompressés sont supprimés après lecture. Les données lues sont supprimées automatiquement 15 jours après la dernière étape d'importation (lecture d'un fichier, ajout d'une source, changement de règles ou écriture), même si vous n'ouvrez pas l'appli. Elles sont supprimées sans possibilité de récupération. L'appli affiche la date dans les Paramètres et à la fin d'une importation. Pour les supprimer plus tôt, ouvrez Paramètres › « Supprimer les données lues ». Les données de HealthPort sont exclues de la sauvegarde Android.

2. Santé Connect

HealthPort fonctionne avec Santé Connect. Vous choisissez les autorisations à accorder et pouvez les modifier à tout moment dans les paramètres de Santé Connect. Si vous refusez certaines autorisations, HealthPort n'écrit pas ces types de données.

Données que HealthPort écrit dans Santé Connect — pour ajouter votre historique :

  • séances d'exercice et parcours ;
  • distance et total des calories brûlées ;
  • fréquence cardiaque ;
  • sommeil ;
  • pas ;
  • poids, masse grasse, masse osseuse, masse d'eau corporelle, métabolisme de base.

Données que HealthPort lit dans Santé Connect :

  • séances d'exercice, sommeil, pas, fréquence cardiaque, poids — pour trouver ce qui est déjà dans Santé Connect et l'ignorer, sans doublons ;
  • distance, total des calories brûlées, masse grasse, masse osseuse, masse d'eau corporelle, métabolisme de base — uniquement les enregistrements écrits par HealthPort lui-même, pour les mettre à jour ou les supprimer lors d'une nouvelle importation de la même source ;
  • les données de plus de 30 jours (une autorisation distincte pour les données passées), car votre historique est en général plus ancien.

HealthPort lit ces données uniquement pendant une importation que vous lancez (elle peut continuer en arrière-plan, avec une notification visible). Dans l'aperçu, elle n'affiche que des nombres. Elle ne stocke pas ces données, ne les affiche pas en graphiques et ne les envoie nulle part.

Quand vous lancez une nouvelle importation, HealthPort remplace ses anciens enregistrements des mêmes sources par les nouvelles données. Pour une source importée auparavant mais pas cette fois, vous choisissez de garder ou de supprimer ses enregistrements. HealthPort ne supprime jamais les enregistrements d'autres applis.

Les données écrites dans Santé Connect restent dans Santé Connect. D'autres applis ne les voient que si vous les y autorisez dans Santé Connect.

HealthPort utilise les données de Santé Connect conformément au règlement sur les autorisations de Health Connect, y compris ses exigences d'utilisation limitée (Limited Use). Nous utilisons ces données uniquement pour les fonctions d'importation que vous voyez dans l'appli. Nous ne les transmettons à personne, ne les utilisons pas pour la publicité et ne les vendons pas.

3. Statistiques d'utilisation, rapports de plantage et données de performance

Les trois sont activés par défaut, comme indiqué dans les Conditions d'utilisation. Vous pouvez les désactiver à tout moment dans Paramètres › « Statistiques d'utilisation ». L'envoi s'arrête dès la désactivation.

Statistiques d'utilisation (Amplitude). L'appli envoie des événements sur son utilisation, par exemple : appli ouverte (langue de l'appli, version d'Android), autorisations accordées (toutes, certaines ou aucune), appli source choisie, lecture d'une archive réussie ou non (succès ou code d'erreur), aperçu affiché, importation lancée et terminée (gratuite ou complète, succès ou erreur), achat lancé, terminé ou échoué, et données supprimées. Ces événements ne contiennent jamais de données de santé ni leur quantité. Avec chaque événement, Amplitude reçoit uniquement : un ID de statistiques aléatoire créé par l'appli, la version d'Android et la plateforme, la langue de l'appli, la version de l'appli, un ID de session, l'heure de l'événement et un ID d'événement aléatoire pour ne pas compter deux fois le même événement. L'appli n'envoie ni votre nom, ni votre e-mail, ni la marque, le fabricant ou le modèle de votre appareil. Nous avons désactivé la collecte de votre adresse IP et de votre localisation (ville et pays). Amplitude stocke ces données dans son centre de données de l'UE.

Rapports de plantage (Firebase Crashlytics, Google). Quand l'appli plante, elle envoie un rapport : la trace technique de l'erreur, le type d'appli source et l'étape d'importation, des informations sur l'appareil au moment du plantage (comme le modèle et la version d'Android) et des identifiants d'installation aléatoires. Les rapports ne contiennent jamais vos enregistrements.

Données de performance (Firebase Performance Monitoring, Google). L'appli mesure sa rapidité : temps de démarrage, affichage des écrans, utilisation du processeur et de la mémoire, durée et résultat de ses requêtes réseau (vers Amplitude et Google Play). Chaque rapport contient des informations sur l'appareil (comme le modèle et la version d'Android) et un identifiant d'installation aléatoire. Google reçoit aussi votre adresse IP et ne l'utilise que pour déterminer le pays d'où vient le rapport. Les données de performance ne contiennent jamais de données de santé ni leur quantité.

Identifiant d'installation Firebase. Crashlytics et Performance Monitoring utilisent un identifiant d'installation aléatoire créé par l'appli (Firebase installation ID). Tant que les statistiques sont activées, Performance Monitoring charge aussi ses paramètres depuis Firebase Remote Config. Avec cette requête, Google reçoit l'identifiant d'installation, le code du pays et de la langue, le fuseau horaire, la version d'Android et le nom du paquet de l'appli.

L'appli n'a pas d'identifiant publicitaire et n'utilise pas Google Analytics.

Finalité : comprendre quelles fonctions marchent, corriger les erreurs et garder l'appli rapide. Nous ne vendons pas ces données. Base légale : notre intérêt légitime à faire fonctionner l'appli et à l'améliorer (art. 6, paragraphe 1, point f, du RGPD). Vous pouvez vous y opposer à tout moment en désactivant les statistiques dans les Paramètres. Durée de conservation : statistiques d'utilisation — 12 mois ; rapports de plantage et leur identifiant d'installation — 90 jours, après quoi Firebase commence à les supprimer de ses systèmes ; données de performance liées à votre adresse IP — 30 jours, autres données de performance — 60 jours ; identifiant d'installation utilisé pour les paramètres — jusqu'à ce que nous demandions à Google de le supprimer, puis Google l'efface dans un délai de 180 jours.

4. Achats

La lecture des fichiers, l'aperçu et l'écriture des 30 derniers jours sont disponibles sans achat. L'importation de tout l'historique est un achat unique sur Google Play.

Google Play gère le paiement. Nous ne voyons jamais les données de votre carte ou de votre banque. L'appli vérifie votre achat sur le téléphone à l'aide d'informations de Google Play (comme le numéro de commande et le statut de l'achat). Google Play nous transmet les détails de la commande (comme le numéro, le produit, le prix, le pays et la date). Nous les conservons aussi longtemps que l'exige le droit fiscal polonais, en général 5 ans à compter de la fin de l'année où l'impôt correspondant est devenu exigible. Les statistiques d'utilisation enregistrent aussi qu'un achat a été lancé, terminé ou a échoué (voir section 3). Le traitement de votre paiement par Google est décrit dans l'Avis de confidentialité de Google Payments : https://payments.google.com/legaldocument?family=0.privacynotice

Base légale : l'exécution du contrat d'achat et nos obligations légales (art. 6, paragraphe 1, points b et c, du RGPD).

5. Rappels

Si vous demandez un rappel pendant la préparation de votre export, l'appli programme une notification sur votre téléphone. Rien ne nous est envoyé.

6. Assistance

Si vous nous écrivez, nous recevons votre adresse e-mail et votre message. Nous les utilisons uniquement pour vous répondre et les conservons 12 mois. Merci de ne pas nous envoyer vos fichiers d'export ni vos données de santé. Base légale : notre intérêt légitime à répondre à votre demande (art. 6, paragraphe 1, point f, du RGPD), ou les mesures liées à votre achat si votre message le concerne (point b).

7. Destinataires des données

  • Amplitude, Inc. (États-Unis) — statistiques d'utilisation, en tant que sous-traitant ; stockage dans l'UE.
  • Google (Firebase Crashlytics, Performance Monitoring, Remote Config) — rapports de plantage et données de performance, en tant que sous-traitant.
  • Google Play — achats, selon les conditions propres à Google.

Personne ne reçoit vos données de santé de notre part, car nous ne les avons pas.

Transferts hors de l'Espace économique européen :

  • Firebase Crashlytics, Performance Monitoring et Remote Config sont des services mondiaux : Google peut traiter et stocker les rapports de plantage et les données de performance partout où Google ou ses agents disposent d'installations, y compris hors de l'EEE (par exemple aux États-Unis). Google LLC est certifiée au titre du cadre de protection des données UE–États-Unis (Data Privacy Framework).
  • Amplitude stocke les statistiques dans l'UE, mais Amplitude, Inc. est une société américaine et son personnel peut accéder aux données depuis les États-Unis si nécessaire. Amplitude déclare respecter le cadre de protection des données UE–États-Unis ; ses conditions de traitement des données prévoient aussi des clauses contractuelles types.

8. Fournir des données est-il obligatoire ? Décisions automatisées

Vous n'avez à nous fournir aucune donnée personnelle pour utiliser HealthPort. Vous pouvez désactiver les statistiques d'utilisation, les rapports de plantage et les données de performance. Les détails de commande ne sont nécessaires qu'en cas d'achat, car Google Play le traite. Nous ne prenons pas de décisions automatisées à votre sujet et ne créons pas de profil.

9. Supprimer vos données

  • Données écrites par HealthPort dans Santé Connect : dans HealthPort, ouvrez Paramètres › « Supprimer tout ce qu'a écrit HealthPort » et confirmez. Seuls les enregistrements de HealthPort sont supprimés, pas les données d'autres applis. Vous pouvez aussi gérer et supprimer des données dans les paramètres de Santé Connect.
  • Données sur votre téléphone : les données lues sont supprimées automatiquement 15 jours après la dernière étape d'importation (voir section 1). Pour les supprimer plus tôt, ouvrez Paramètres › « Supprimer les données lues ». La désinstallation de HealthPort supprime tout son stockage privé.
  • Statistiques, rapports de plantage et données de performance : désactivez-les dans les Paramètres. Pour demander la suppression des statistiques déjà envoyées, écrivez à healthport.support@gmail.com en indiquant votre ID de statistiques. Vous le trouverez dans les Paramètres sous « ID des statistiques ». Nous ne savons pas qui vous êtes : sans cet ID, nous ne pouvons pas retrouver vos données. Les rapports de plantage sont supprimés automatiquement après 90 jours, les données de performance après 30 ou 60 jours (voir section 3). Ils ne sont liés qu'à des identifiants d'installation aléatoires, que nous ne pouvons pas relier à vous.

10. Vos droits

Selon le RGPD, vous avez le droit d'accéder à vos données, de les rectifier, de les effacer, d'en limiter le traitement, de vous opposer au traitement et à la portabilité. Lorsque nous nous fondons sur notre intérêt légitime (statistiques, rapports de plantage, données de performance, e-mails d'assistance), vous pouvez vous y opposer à tout moment ; pour les statistiques, les rapports de plantage et les données de performance, l'interrupteur des Paramètres le fait immédiatement. Pour exercer vos droits, écrivez à healthport.support@gmail.com.

Vous pouvez aussi adresser une réclamation à une autorité de protection des données. En Pologne, il s'agit du Président de l'Office de protection des données personnelles (Prezes Urzędu Ochrony Danych Osobowych), ul. Stawki 2, 00-193 Varsovie, https://uodo.gov.pl. Vous pouvez aussi le faire dans le pays de l'UE où vous vivez (en France, la CNIL).

11. Sécurité

Les données de santé sont traitées uniquement sur votre téléphone et restent dans le stockage privé de l'appli et dans Santé Connect. Les statistiques, les rapports de plantage et les données de performance sont envoyés par des connexions chiffrées (HTTPS).

12. Enfants

HealthPort est destinée aux personnes de 16 ans et plus.

13. Modifications

Si nous modifions cette politique, nous mettrons à jour la date d'entrée en vigueur et afficherons la nouvelle version dans l'appli et sur la page Google Play.
